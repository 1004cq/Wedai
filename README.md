# Wedai

基于 [LobeHub](https://github.com/lobehub/lobehub) 的二次开发商业化版本。

> 完整实现：**用户系统 + 付费订阅 + 积分计费 + 管理后台**

## 项目定位

本仓库采用 **方案 C：完全自己二次开发** 路线，在官方开源版本基础上深度定制，打造可独立运营的商业化 AI Agent 平台。

### 核心功能规划

- [x] 复用官方 Better Auth 用户系统（邮箱 + SSO）
- [ ] 用户余额 / 套餐 / 邀请体系
- [ ] Stripe + 易支付（微信/支付宝）双支付通道
- [ ] 模型调用实时积分扣费中间件
- [ ] 订单、流水、对账系统
- [ ] 完整管理后台（用户、订单、模型价格、套餐配置）
- [ ] 定价页 + 用户中心 + 充值流程

## 技术栈

- 前端 / 后端：Next.js + React 19 + tRPC
- 认证：Better Auth
- 数据库：PostgreSQL + Drizzle ORM
- 支付：Stripe + 易支付/虎皮椒
- UI：Ant Design + @lobehub/ui
